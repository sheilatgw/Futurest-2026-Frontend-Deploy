# Next.js Template Repository

## Pendahuluan

### 1. Kloning repository ini dengan salah satu cara berikut:

```bash
git clone https://github.com/futurest2025/frontend-futurest2026.git
```

### 2. Instalasi dependensi

Disarankan untuk menggunakan **bun**, agar **husky hooks** dapat berfungsi dengan benar.

```bash
bun install
```


---

### 3. Menjalankan server pengembangan

Jalankan perintah berikut untuk memulai server pengembangan:

```bash
bun dev
```

Kemudian buka [http://localhost:3000](http://localhost:3000) di browser untuk melihat hasilnya.  
Kamu dapat mengubah isi halaman dengan mengedit file `src/app/page.tsx`.

---

### 4. Pesan Commit

Template ini menggunakan standar **Conventional Commit** untuk menjaga konsistensi dan keterbacaan pesan commit.  
Pastikan setiap commit mengikuti format tersebut.  
Untuk detail lebih lanjut, baca panduan di:  
[https://www.conventionalcommits.org/en/v1.0.0/](https://www.conventionalcommits.org/en/v1.0.0/)
